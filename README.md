# 🛍️ Shop Website

## 📌 About the Project
This is a responsive and modern Shop Website designed to provide customers with a simple and enjoyable online shopping experience. The website allows users to explore products, view product details, and discover different shopping categories.

## ✨ Features
- Modern and attractive user interface
- Responsive design for desktop, tablet, and mobile devices
- Product display section
- Product categories
- Shopping cart interface
- Easy navigation
- Attractive product images and layouts

## 🛠️ Technologies Used
- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Interactive functionality
